Workflow

How we deploy and run the NERO stack on the arm, step by step.

Deployment workflow

1. Download and Extract

Download the nero_deployment_kit_v2.zip file and extract its contents to your local computer.

2. Verify Hardware

Ensure the computer is physically connected to the AgileX Nero CAN interface via USB, the overhead Intel RealSense D435 camera, and the wrist Intel RealSense D405 camera.

3. Start the Hardware Network

Open a terminal in the extracted folder and run the setup script to bring the CAN network online:

bash setup_can.sh

(Note: You will be prompted for the sudo password to allow communication with the motors).

4. Apply the Software Patch

The robot currently has safety locks engaged and a bug mapping the gripper to the wrist joint. Copy the patched file over the existing system file to fix it:

cp patched_robot_wrapper.py ~/lerobot/src/lerobot/rollout/robot_wrapper.py

5. Clean the Dataset (Optional)

Before retraining, run the included quality scorer to identify and filter out bad demonstrations (like jittery teleoperation or missed grasps).

conda activate nero-RDP2026Nov python3 quality_scorer.py --dataset ~/Desktop/RDP2026Nov/datasets/nero_conveyor_sort --budget-percent 75.0

This analyzes the dataset, generates a CSV report, and outputs a curated episode list to use for training.

6. Run the AI Policy

Clear the physical workspace, place the target object on the conveyor, and keep your hand on the physical Emergency Stop button. Run:

bash run_rollout.sh

To stop the robot at any time, press the Esc key on the keyboard.
